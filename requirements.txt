# ============================================================
# ReachInbox Email Scheduler – System Requirements
# ============================================================
# This is a Node.js / TypeScript project (not Python).
# This file documents all prerequisites needed to run it.
# ============================================================

## Runtime
- Node.js >= 18.x (tested on v20.18.0)
- npm >= 10.x

## Infrastructure (via Docker or installed locally)
- Docker & Docker Compose (recommended)
- Redis 7.x (port 6379)
- PostgreSQL 16.x (port 5432)
- Elasticsearch 8.x (port 9200)
